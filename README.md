# RadarOne2026

A radar development project using the TI IWR6843ISK mmWave radar.

## Goals

- Detect objects
- Measure distance
- Measure relative velocity
- Determine object angle
- Track objects
- Eventually integrate radar into an autonomous rover

## Hardware

- TI IWR6843ISK
- Computer
- USB connection

## Software

- Python
- C/C++
- Git
